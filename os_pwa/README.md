# 操作系统刷题 PWA

王道《操作系统》分节习题（选择部分）：**15 组 457 题**，主题色为 WorkBuddy 绿色系。
**已含逐题答案与详细解析**（2026-09-08 由 AI 按王道知识点逐题撰写，含调度算法/银行家算法/页面置换/磁盘调度等全部计算题的推演过程）。

## 启动

双击 `启动刷题.bat`（零依赖，需 Node.js 或 Python 任一），浏览器自动打开
`http://127.0.0.1:8769/index.html`。端口 8769，与其他刷题应用（组成原理 8765 /
计网 8767 / 数据结构 8768）不冲突。

- 数据文件 `data/ch0.json … ch14.json` + `data/chapters.json`，可直接编辑
- 答题进度自动保存在本机（IndexedDB，localStorage 兜底），支持导出/导入 JSON
- 首次访问后 Service Worker 全量预缓存，可完全离线使用
- 快捷键：A–D 作答、←/→ 切章、1–9 跳章、Ctrl+Enter 展开答案、Ctrl+R 重做本章

## 答案与解析

- 每题都有 `a`（答案字母）与 `x`（详细解析，含计算题推演），点选即判分、答完显示解析
- 多小题（ch5 Q31、ch7 Q34）选项已组合化为 `①X ②Y` 形式，答案对应组合
- 想修改某题的答案/解析：直接编辑 `data/chN.json` 的 `a`/`x` 字段，保存刷新即可（改完建议把 `sw.js` 的 CACHE_VERSION 加 1）
- 答案文件保存在 `tools/ans/ans-00.json … ans-14.json`，可复用 `tools/merge.py` 重新合并

## 工具

- `tools/parse.py`：从 `D:\PersonalDownload\408\os题目.txt` 重新生成题库 JSON
  （含 LaTeX 剥壳、代码块/表格并入题干、源文重复块去重、重复题号顺延）
- `tools/fixups.json`：多小题（①②组合）的组合选项定义（ch5 Q31、ch7 Q34）
- `tools/icons.py`：重新生成绿色系 PWA 图标
- `tools/merge.py`：合并答案与解析（见上）
