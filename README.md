# 操作系统刷题 PWA（修订版）

由原单文件 `操作系统_选择_修订版.html` 重构的渐进式 Web 应用（PWA）：**15 章 428 题**，离线可用、进度自动保存。

## 一、题目和解析在哪改（重点）

**所有题目都在 `data/` 目录，页面代码里没有任何题目**，改题只动这个目录：

```
data/
├── chapters.json     # 章节目录（序号 idx、章节名 name、题数 count）
├── ch0.json          # 第 1 章：操作系统基本概念（12 题）
├── ch1.json          # 第 2 章：发展与分类（14 题）
├── ch2.json          # 运行环境（16）
├── ch3.json          # 操作系统结构（17）
├── ch4.json          # 进程与线程（58）
├── ch5.json          # 处理机调度（32）
├── ch6.json          # 同步与互斥（46）
├── ch7.json          # 死锁（28）
├── ch8.json          # 内存管理基础（52）
├── ch9.json          # 虚拟内存管理（35）
├── ch10.json         # 文件系统基础（37）
├── ch11.json         # 文件目录与共享（14）
├── ch12.json         # 文件系统实现（12）
├── ch13.json         # I/O管理概述（32）
├── ch14.json         # 5.2 设备独立性软件（0）
└── ch15.json         # 5.3 磁盘和固态硬盘（23）
```

### 每道题的格式

```json
{
  "id": 1,                         // 本章内唯一编号（题号显示为“第N题”，答题记录靠它定位）
  "q": "题干文字（ ）。",
  "o": {                           // 选项：只能用 A/B/C/D 作键
    "A": "选项内容",
    "B": "选项内容",
    "C": "选项内容",
    "D": "选项内容"
  },
  "a": "C",                        // 正确答案，必须是 o 里存在的键
  "x": "解析文字，答完后展示"
}
```

### 常见修改操作

1. **改题干/选项/解析/答案**：直接改对应文字即可，注意 JSON 字符串里：
   - 双引号要写成 `\"`；换行写成 `\n`；
   - 中文标点、括号可直接写；不要在最后一条选项后多写逗号。
2. **新增一道题**：在对应 `chN.json` 数组末尾照格式加一个对象，`id` 取本章未用过的新数字（接着最大 id 往后排即可，不要求连续）；然后把 `chapters.json` 里该章 `count` 加 1。
3. **删除一道题**：删掉整个对象，并把 `chapters.json` 的 `count` 减 1（答题记录中该题的残留数据会被自动忽略）。
4. **新增/删除整章**：新增 `ch15.json` 后，在 `chapters.json` 追加 `{"idx":15,"name":"章节名","count":题数}`；同时把 `sw.js` 顶部的 `CHAPTER_COUNT` 改成新的总章数。删章做反向操作。
5. **改章节名**：只改 `chapters.json` 的 `name`。

### 改完必做

- 在本目录命令行运行 `node check-data.cjs` 自检（JSON 合法性、答案是否在选项中、id 重复、题数与目录是否一致）。
- **刷新浏览器即可看到新题目**（题库 JSON 采用“网络优先”策略，无需清缓存）。
- 若浏览器仍显示旧内容：按 Ctrl+F5 强制刷新；或把 `sw.js` 里 `CACHE_VERSION` 的 `os-v1` 改成 `os-v2`。
- 用记事本编辑请**另存为 UTF-8 编码**（推荐用 VS Code，自动保证格式）。

## 二、如何运行

PWA 的 fetch 与 Service Worker 需要 http 环境，**不能直接双击 index.html**。

1. Windows 双击 `启动刷题.bat`（本机有 Node.js 或 Python 即可，自动打开浏览器，端口 8766）。
2. 或命令行：`node serve.cjs 8766` / `python -m http.server 8766`，访问 `http://127.0.0.1:8766/index.html`。
3. 部署到手机：把整个文件夹放到静态托管（GitHub Pages 等），手机浏览器首次打开后断网也能用；Safari「分享→添加到主屏幕」、Chrome「安装应用」后全屏运行。

## 三、目录与优化说明

```
os-pwa/
├── index.html              页面外壳（无题目）
├── manifest.webmanifest    PWA 清单
├── sw.js                   Service Worker（题库 network-first，其余 cache-first，预缓存全部资源）
├── serve.cjs               零依赖本地服务器
├── check-data.cjs          题库自检脚本（改题后运行）
├── 启动刷题.bat             双击启动
├── css/style.css           样式（含移动端适配）
├── js/app.js               应用逻辑
├── data/                   ★ 题库在这里，自行修改 ★
└── icons/                  应用图标
```

对照《方式.md》落实：数据/视图分离按章 fetch、分片渲染 + content-visibility、事件委托（1 个监听器）、中文双字倒排搜索索引、IndexedDB 持久化（自动迁移旧版 `os_quiz_state_v2` 记录）、进度导入/导出、移动端章节抽屉 + 左右滑动切章 + 44px 触摸区域、Service Worker 全量预缓存离线可用。
